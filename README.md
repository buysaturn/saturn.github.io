# Saturn Landing Page

Современный, производительный лендинг для софта Saturn в стиле catlavan.net / топовых продуктов.

## Что внутри:
- **Космический интерактивный Canvas**: анимированное звездное поле и созвездия, реагирующие на разрешение экрана.
- **Интерактивный симулятор Obsidian UI**:
  - Рабочие вкладки: Combat (Silent Aim, FOV, Hit Chance), Visuals (ESP Boxes, Skeleton, Chams, Tracers), Player (SpeedHack, NoClip, Infinite Jump), Cloud Settings.
  - Живой холст мишени: изменения чекбоксов и слайдеров мгновенно отражаются на манекене (рисуется ESP-бокс, здоровье, скелет R15/R6, целевой квадрат и радиус круга FOV).
- **Сетка возможностей (Features)**: подробное описание Silent Aim, DirectX оверлея, Kernel-level обхода, облачной синхронизации.
- **Тарифная сетка (Pricing)**: 1 День (99 ₽), 30 Дней (399 ₽), Lifetime (999 ₽) с интерактивным модальным окном оформления заказа и выбором платежной системы.
- **Мониторинг инфраструктуры**: статус обхода (Undetected), аптайм лоадера и серверов.
- **Интерактивный FAQ**: разворачивающиеся аккордеоны.
- **Адаптивность**: полноценный мобильный и десктопный адаптив на Tailwind CSS + Lucide Icons.

## Как запустить / просмотреть:
Просто откройте файл `index.html` в любом браузере:
```powershell
Start-Process .\landing\index.html
```
Или запустите локальный HTTP-сервер:
```powershell
python -m http.server 8000 --directory landing
```
И перейдите по адресу `http://localhost:8000`.
